# SchoolHop Foundation Website

A responsive single-page website for the SchoolHop Foundation, focused on rural learner transport, sponsorship lead generation, and digital marketing campaign planning.

## Included

- Responsive Home, About, impact, gallery, sponsorship, and Contact sections
- JavaScript multi-step sponsorship flow
- Client-side contact lead form validation and confirmation
- SEO title, meta description, and keyword metadata
- Keyword research, landing-page copy, SMART campaign objective, and proposed search advertisement

## Run locally

Open `index.html` in a browser, or serve the folder with a local web server.
